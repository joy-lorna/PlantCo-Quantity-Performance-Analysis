# PlantCo-Quantity-Performance-Analysis

Power BI Dashboard — Dynamic YTD vs PYTD Performance Report

This repository hosts the data analysis and performance reporting for **PlantCo**. The project focuses on analyzing quantity-based performance metrics to identify sales trends, top-performing product categories, and regional growth opportunities.

## 📖 Project Write-up
A detailed breakdown of the analysis, including data visualizations and business recommendations, is available on Kaggle.

[![Kaggle](https://img.shields.io/badge/Kaggle-Project_Writeup-00BBFF?style=for-the-badge&logo=kaggle)](https://www.kaggle.com/writeups/joylorna/plantco-quantity-performance-analysis)

**Key Objectives & Insights:**
* **Quantity Metrics:** Tracking year-to-date (YTD) quantity performance against previous years.
* **Product Breakdown:** Identifying the highest volume drivers across Indoor, Landscape, and Outdoor categories.
* **Trend Analysis:** Visualizing monthly performance fluctuations to pinpoint seasonal demand.
* **Account Management:** Analyzing specific account performance to optimize distribution strategies.

## 🛠️ Tech Stack
* **Analysis:** Python (Pandas, NumPy)
* **Visualization:** Matplotlib, Seaborn, or Power BI/Tableau (if applicable)
